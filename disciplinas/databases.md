# Banco de Dados

COM10129 · 4º período sugerido na matriz histórica

Modelagem, consulta e consistência de dados persistentes.

## Conceitos centrais

- Modelo relacional
- SQL e integridade
- Normalização e transações

## Um exemplo para conectar teoria e prática

Separar livros, autores e empréstimos evita misturar entidades com ciclos de vida diferentes. Chaves e restrições tornam parte dessas regras verificável pelo banco.
