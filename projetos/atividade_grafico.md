# Gráficos com Builder

Exercício de exibição de dados com JFreeChart, separando a construção do gráfico das etapas que coordenam sua montagem.

**Projeto de Sistemas de Software · UFES**

Java 8 · Swing · JFreeChart · Builder

## O que o trabalho permite observar

- Separação entre Builder, Diretor e representação do gráfico.
- Leitura e apresentação de dados em visualizações.
- Organização de uma interface desktop em camadas.

## Relação com a formação

Este caso conecta o eixo **Software e interfaces** aos arquivos e decisões de um projeto concreto. A apresentação preserva o recorte do trabalho: Acervo acadêmico. Dados e imagens de entrada precisam de contexto próprio antes de serem reutilizados.

## Explorar o material

O código deste trabalho permanece em acervo privado. Este resumo apresenta apenas seu contexto e os conceitos técnicos.
