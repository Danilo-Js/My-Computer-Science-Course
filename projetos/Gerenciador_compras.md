# Gerenciador de compras

Trabalho web em grupo com páginas HTML/CSS, API Express e persistência SQLite para explorar operações de produtos e integração entre interface e backend.

**COM10615 · Tópicos Especiais em Programação I · UFES/Alegre**

HTML · CSS · JavaScript · Node.js · Express · SQLite

## O que o trabalho permite observar

- Rotas HTTP e troca de dados com a interface.
- Operações de persistência e criação de tabelas SQLite.
- Separação entre páginas, serviços e acesso a dados.

## Relação com a formação

Este caso conecta o eixo **Software e interfaces** aos arquivos e decisões de um projeto concreto. A apresentação preserva o recorte do trabalho: Aplicação acadêmica; dados e fluxos não representam operação comercial. O arquivo LICENSE e o campo license do package.json devem ser consultados em conjunto, pois apresentam declarações diferentes.
