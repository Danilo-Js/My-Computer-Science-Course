# Estação climática com Observer

Exercício Java que conecta uma estação climática a diferentes painéis. Mudanças nos dados são propagadas para observadores de estatísticas e valores extremos.

**Estudo de padrões de projeto · acervo de computação**

Java 8 · Swing · Observer · JFreeChart

## O que o trabalho permite observar

- Registro de observadores em um objeto observado.
- Propagação de mudanças para painéis independentes.
- Separação entre modelo de dados, apresentação e estatísticas.

## Relação com a formação

Este caso conecta o eixo **Software e interfaces** aos arquivos e decisões de um projeto concreto. A apresentação preserva o recorte do trabalho: Os dados representam o cenário didático do exercício; não há integração com sensores físicos ou serviço meteorológico afirmada nesta apresentação.
