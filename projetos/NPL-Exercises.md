# Exercícios de linguagem natural

Acervo de exercícios e trabalhos de Processamento de Linguagem Natural, com scripts de análise de texto, transdutores e um exercício de predição por n-gramas.

**Tópicos Especiais em Informática II · PLN · UFES**

Python · Corpus textual · Transdutores · N-gramas

## O que o trabalho permite observar

- Leitura e preparação de corpus para análise.
- Representação de padrões linguísticos com transdutores.
- Predição baseada em frequências e contexto de n-gramas.

## Relação com a formação

Este caso conecta o eixo **Inteligência artificial e linguagem natural** aos arquivos e decisões de um projeto concreto. A apresentação preserva o recorte do trabalho: São exercícios didáticos, não um modelo de linguagem de produção. O nome histórico do repositório é NPL-Exercises; o tema estudado é NLP/PLN.
