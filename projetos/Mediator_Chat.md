# Chat com Mediator

Exercício Java de comunicação entre participantes de uma sala de chat, centralizando a coordenação no padrão Mediator.

**Projeto de Sistemas de Software · UFES**

Java 8 · Maven · Mediator

## O que o trabalho permite observar

- Desacoplamento entre participantes da conversa.
- Coordenação de mensagens por um mediador.
- Responsabilidades de usuários, bots e sala de chat.

## Relação com a formação

Este caso conecta o eixo **Software e interfaces** aos arquivos e decisões de um projeto concreto. A apresentação preserva o recorte do trabalho: Exercício de padrão de projeto. Não é serviço de mensagens distribuído nem plataforma de chat em produção.
