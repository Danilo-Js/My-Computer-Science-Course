# Gráficos de dados do npm

Script Python para consultar dados públicos do npm e explorar a relação entre datas de publicação de versões e contagens de downloads de um pacote.

**Ferramenta de estudo e apoio à análise de bibliotecas**

Python · requests · Matplotlib · API npm

## O que o trabalho permite observar

- Consumo de duas fontes de dados e associação por data.
- Preparação de séries temporais para visualização.
- Leitura crítica de métricas de distribuição de pacotes.

## Relação com a formação

Este caso conecta o eixo **Dados e análise** aos arquivos e decisões de um projeto concreto. A apresentação preserva o recorte do trabalho: Downloads de pacote não equivalem a usuários, clientes, instalações ativas ou receita. A associação no script usa datas de publicação e não identifica qual versão foi efetivamente instalada.
