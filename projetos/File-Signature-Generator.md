# Assinaturas de arquivos

Script de estudo de computação forense para percorrer um diretório e calcular hashes dos arquivos. O interesse é observar como uma assinatura ajuda a comparar integridade entre cópias.

**Tópicos Especiais em Redes de Computadores I · Computação Forense · UFES**

Python · hashlib · Sistema de arquivos

## O que o trabalho permite observar

- Leitura de arquivos em blocos, sem carregar todo o conteúdo na memória.
- Percurso de subdiretórios e tratamento de falhas de leitura.
- Comparação de assinaturas e limites dos algoritmos disponíveis no ambiente.

## Relação com a formação

Este caso conecta o eixo **Sistemas e redes** aos arquivos e decisões de um projeto concreto. A apresentação preserva o recorte do trabalho: Hash de arquivo não é assinatura digital com certificado nem comprovação de autoria. A saída do script não substitui um procedimento pericial completo.
