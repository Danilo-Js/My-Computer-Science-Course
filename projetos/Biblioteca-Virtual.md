# Biblioteca Virtual

Concepção e documentação de uma biblioteca virtual, com requisitos, entrevistas, questionários e protótipos. O trabalho explora como transformar necessidades de usuários em uma proposta de sistema.

**Engenharia de Requisitos de Software · UFES**

Requisitos · Modelagem · Prototipação · Documentação

## O que o trabalho permite observar

- Elicitação de necessidades e organização de requisitos.
- Relação entre pesquisa, escopo e protótipos de interface.
- Registro das decisões que antecedem a implementação.

## Relação com a formação

Este caso conecta o eixo **Software e interfaces** aos arquivos e decisões de um projeto concreto. A apresentação preserva o recorte do trabalho: Protótipos e documentação não comprovam implantação, operação comercial ou vendas. Documentos de pesquisa devem ser lidos no contexto acadêmico original.
