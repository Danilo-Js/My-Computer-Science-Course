# My Computer Science Course

I'm Danilo Lima. This repository connects concepts and projects from my Computer Science studies at the Federal University of Espírito Santo, Alegre campus.

[Português](README.md) · [Curriculum and study notes](grade.md) · [GitHub profile](https://github.com/Danilo-Js)

## Start with the work

- [React Native e-commerce components](projetos/react-native-ecommerce-components.md) and [TechEcommerce](projetos/TechEcommerce.md): a final-project library and its demonstration app.
- [Brazukol Compiler](projetos/Brazukol-Compiler.md): lexical analysis and selected syntactic/semantic checks in an educational IDE.
- [Kanb-Ex](projetos/Kanb-Ex.md): Vue components, state and browser persistence in a coursework Kanban board.
- [Prolog tank battle](projetos/AI-Tank-Battle.md) and [car race](projetos/prolog-car-race.md): sensors, rules and agent decisions.
- [Natural language processing exercises](projetos/NPL-Exercises.md): corpus processing, transducers and n-grams.
- [File signatures](projetos/File-Signature-Generator.md): integrity checks with Python.
- [Virtual Library](projetos/Biblioteca-Virtual.md): requirements and interface prototypes.
